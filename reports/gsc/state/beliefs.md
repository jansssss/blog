# 사이트에 대한 현재 믿음

에이전트가 지금 사실이라고 믿고 있는 것들. **요약본이 아니라 작업 가설의 목록이다.**
각 항목에는 근거(어느 판정에서 나왔는지)를 붙인다.
판정에서 틀린 것으로 드러난 믿음은 지운다 — 쌓아두면 판단을 흐린다.

형식:
```
- <믿는 것> — 근거: <판정 id 또는 관측> (신뢰도: 높음/보통/낮음)
```
