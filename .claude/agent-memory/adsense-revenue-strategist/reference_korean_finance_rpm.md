## 한국 금융/대출 카테고리 AdSense 단가 특성

### RPM 추정 범위 (한국 금융 카테고리)

| 서브 카테고리 | 예상 RPM | 주요 이유 |
|---------------|----------|-----------|
| 주택담보대출 / 전세대출 | ₩3,000~₩5,000 | 은행·보험사 광고주 경쟁 극심 |
| 신용대출 / 한도 | ₩2,500~₩4,000 | 핀테크 광고주 활발 |
| 청년/정책자금 대출 | ₩1,500~₩3,000 | 정책 광고 포함 |
| 신용점수 관리 | ₩2,000~₩3,500 | 신용평가사 광고 |
| 양도소득세 / 연말정산 | ₩2,500~₩4,500 | 세무사/회계사 광고주 |
| 주택청약 | ₩1,500~₩2,500 | 부동산 광고주 |
| 금리 비교 / 은행 비교 | ₩2,000~₩3,500 | 비교 사이트 광고 |

### 고CPC 키워드 클러스터 (한국)

1. **대출 갈아타기 관련**: "주담대 갈아타기", "신용대출 환승" — CPC ₩500~₩1,500
2. **대출 한도 관련**: "DSR 계산", "LTV 기준", "대출 한도 늘리기" — CPC ₩400~₩1,200
3. **보험/보증 관련**: "전세보증보험 HUG", "SGI 보증" — CPC ₩600~₩1,800
4. **절세 관련**: "양도세 비과세", "종합소득세 절세" — CPC ₩700~₩2,000
5. **정책대출**: "디딤돌대출 조건", "버팀목대출 한도" — CPC ₩300~₩900

### 핵심 원칙

- 금융 카테고리는 YMYL(Your Money Your Life) 영역 → 구글 EAT 신호 필수
- 계산기 + 가이드 조합: 체류시간 ↑ → RPM ↑
- 시즌성: 연말정산(11~2월), 청약(상시), 세금 신고(5월) 피크 시즌 활용

**Why:** RPM 역산을 통한 현실적 트래픽 목표 설정에 필요
**How to apply:** 콘텐츠 우선순위 결정 시 위 RPM 범위 기준으로 고단가 주제 우선 배치
